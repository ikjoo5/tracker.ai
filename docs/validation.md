- `bash scripts/setup.sh`: 독립 Python 가상환경 설치, 모델 SHA-256 검증, `npm ci`, 프런트엔드 빌드 완료.
- `.venv/bin/python -m unittest discover -s tests -v`: 24개 통과.
- `SMOKE_VIDEO=/tmp/opencv-walkthrough.mp4 node scripts/browser-smoke.mjs`: Chromium 브라우저 통과. 기존 합성 영상 분석, BBox/히트맵 전환, 구역 필터, CSV 다운로드, 모바일 가로 넘침 없음, 실제 영상 업로드, 사전학습 모델 결과 확인. 브라우저 예외0건.
- 합성 마트:36초·108표본·8트랙·737검출. 구역별 관찰시간 합계245.666인·초로 전체와 일치.
- 사전학습 실제 영상: OpenCV 공개 `vtest.avi` 앞12초·36표본·41검출·4임시트랙. 이 영상은 마트가 아닌 야외 보행자 검증용이며 실제 마트의 정확도 평가가 아니다.
- 두 합성 결과 MP4는36초, 두 실제 추론 검증 MP4는12초. OpenCV로 열기·재생시간 확인. API의 MP4 Range 요청 확인.

검증한 항목은 실행·수집·시간 가중 집계·내보내기다. 정확도/재현율, ID 유지 성능, 실제 마트 체류 오차는 정답 라벨이 없어 평가하지 않았다. 새 학습이나 카페/마트 데이터 미세조정은 하지 않았으며 사전학습 모델을 사용한다.

## 실제 공개 매장 기본 데모 검증

Intel `store-aisle-detection.mp4` CC BY 4.0 원본 SHA-256을 확인한 뒤8–60초를52초·15fps로 발췌했다. 기본 API는 이 실제 파일과 출처 메타데이터를 사용하며, 합성 파일이 있어도 기본 실제 영상이 없으면503을 반환한다.

사전학습 모델로156표본·372검출·18임시트랙(2회이상관찰16)을 수집했다. ID분리가 있어18을 실제 방문자수로 해석하지 않는다. 누적 관찰123.996인·초로 구역별 합계와 일치한다. 검출된 프레임과 원시좌표에서 BBox/히트맵을 생성했다. 출력은 원본을 가리지 않는54px상단·70px하단 여백을 포함한720×528,H26415fps52초이다. 영상과JSON/CSV에CC BY4.0출처를 기록한다.

추가6개 테스트는 실제기본데모·합성대체금지·manifest오류·출처유지·실제모델경로·CSV출처를 검증한다. 새 모델 학습·정확도 평가는 하지 않았다.

`node scripts/browser-smoke.mjs` 최종 실제 매장 기본 데모 통과: source.kind=public-retail, MobileNet-SSD, CC BY4.0출처, BBox/히트맵 전환, 구역필터,CSV다운로드,모바일넘침없음,브라우저예외0건. 업로드는 이전 통합 검증에서 별도통과. 실제매장 결과영상2개모두H264,720×528,15fps,52초로확인.

## 3D 그래픽 체류맵

- `npm run test:floor`:14개 사례 통과. 네 모서리 원근변환, 실제 관찰 간격, 시간 구간 경계, Gaussian 합계 보존, 화면 아래 잘린 발 제외, 영역 밖 제외, 빈 데이터, 퇴화 보정점 거부,512×512격자 처리를 검증했다.
- `npm run export:floor`: 실제372관찰 중296투영,59잘린발·17영역밖 제외. 투영98.665인·초와 격자합계일치.
- `node scripts/capture-floor.mjs`: 저장된 실제 관찰 결과로 WebGL3D 렌더링. 시점 변경·매대표시·시간필터가 그래픽과 집계를 바꾸는지, PNG다운로드·모바일폭·페이지예외0건을 확인했다.
